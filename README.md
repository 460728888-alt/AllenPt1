# Allen股票分析1.0（V1.7）

新增股票利润亏损计算器：按个人费率估算买入总成本、卖出到账、净盈亏、净收益率、保本卖价、止损结果、目标利润卖价和参考资金最多可买股数。佣金、最低佣金、卖出印花税和双向过户费均可由每位用户单独设置并云端保存。

登录会话改为 PostgreSQL 持久保存。管理员可查看用户是否在线、最近活动、最近登录和登录设备数，可让指定用户的所有设备强制退出，并可导出不含密码与登录凭证的 JSON 安全备份。连续输错密码 5 次会临时锁定 15 分钟。

新增“个人买入与卖出价格计划”：股票详情显示回调关注区间、突破确认价格、防守价格和两档止盈参考价；我的持仓会结合个人成本、数量、投资周期和风险偏好计算预计防守结果。登录检查会对持仓防守价、止盈价和股票池回调区间生成账号级提醒。

股票详情新增真实公司资料、主要财务指标和公司公告。不同账号的股票池、持仓和投资逻辑分别保存到 PostgreSQL，彼此不共享；登录时会自动检查个人股票池并显示未读风险提醒。

“趋势预测中心”支持任意有效沪深 A 股六位代码，可查看未来 5、20、60 个交易日的历史条件概率、跑赢上证综合指数的概率、收益区间、相似样本数、后段样本验证命中率和当前市场环境。所有专业指标均使用中文表达。

AI 智能选股现从约 1200 只成交较活跃的沪深 A 股扩大样本中筛选；投资周期和风险偏好会参与量化排序。结果仅用于研究辅助，不连接国信金太阳账户，也不执行交易。

管理员可发布站内通知。每位用户进入网站后会看到未读通知，确认后按账号记录为已读。

管理员控制的小范围私人股票研究与决策辅助 Web App。

## 当前能力

- 管理员创建用户，不开放注册
- 数据库登录会话、在线状态、连续登录失败保护与管理员强制下线
- 管理员导出不含密码和登录凭证的安全备份
- 股票搜索与个人股票池
- 真实市场价格、历史行情、均线和波动数据
- 股票详情九大研究模块
- 短期 / 中期 / 长期条件评分
- 股票池通用价格计划与个人持仓价格计划
- 含交易费用的股票盈亏计算器、保本价、目标价、止损结果和最大整手数量
- 每位用户单独保存自己的交易费率设置
- 回调关注区间、突破确认价、防守价、两档止盈参考价和预计防守结果
- 股票池、持仓与投资逻辑按账号云端保存，用户之间完全隔离
- 登录自动风险检查、账号级提醒、未来事件、每日简报
- DeepSeek 中文 AI 股票研究对话
- AI 对话会使用该股票的真实行情、公司资料、财务数据和最新公告
- 国信金太阳可搜索的沪深 A 股有限样本智能筛选
- 每位用户每天最多 40 次 AI 请求，控制接口费用
- 未来 5 / 20 / 60 个交易日趋势概率、市场环境与后段样本验证（不消耗 AI 余额）
- 每位用户的趋势计算记录保存到 PostgreSQL
- 真实公司资料、主要财务指标、财务历史和可核验公司公告
- 每个真实数据源显示连接状态、更新时间和字段完整度

## 本地运行

```bash
npm install
APP_USERNAME=allen APP_PASSWORD=allen123 npm start
```

打开 `http://localhost:10000`。

## Render 环境变量

- `APP_USERNAME`：登录用户名
- `APP_PASSWORD`：登录密码（必须在 Render 中设置）
- `DATABASE_URL`：PostgreSQL 内部连接地址，用于保存用户账号、个人数据、提醒与预测记录
- `AI_API_KEY`：DeepSeek API 密钥，只能保存在 Render，不能上传 GitHub
- `AI_BASE_URL`：`https://api.deepseek.com`
- `AI_MODEL`：`deepseek-chat`

## 重要说明

行情和公开研究数据可能延迟。本项目用于研究辅助，不构成投资建议。智能选股是扩大样本比较，并非一次扫描全部 A 股；网站不会读取国信金太阳账户、持仓或交易权限，也不会自动下单。行业指数、精确未来事件日历和券商专属数据在没有稳定授权来源时会明确说明，不会由 AI 编造。
